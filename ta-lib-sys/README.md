# oxi-ta-lib-sys

Autogenerated Rust FFI bindings for the [TA-Lib](https://ta-lib.org/) technical analysis library.

This crate is a maintained fork of [virtualritz/ta-lib-rs](https://github.com/virtualritz/ta-lib-rs) with critical build script fixes:
* **Incremental build fix:** properly configured `cargo:rerun-if-changed` to prevent unnecessary full recompilations on client code changes.
* **Faster build:** parallel compilation (`make -j`) for the bundled C source.
* **Build script optimization:** removed overhead from bindgen callbacks.

This crate bundles the C source code of TA-Lib v0.4.0, which is built from source and wrapped by default.

## Cargo Features

* `use_system_lib` – Link against the system's installed C TA-Lib instead of building the bundled source.
